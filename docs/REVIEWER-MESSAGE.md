Сделал на HTML, CSS и JavaScript без фреймворков и сборки. Все пункты задания реализованы: добавление, выполнение и удаление задач, сохранение после перезагрузки через localStorage.

Сверх задания добавил канбан с перетаскиванием, список и календарь, поиск, метки, приоритеты, подзадачи, статистику и компактный 3D-обзор. Из календаря можно скачать .ics для календаря телефона: активные задачи со сроками и текущими фильтрами экспортируются событиями на весь день. Это снимок без автосинхронизации, заметки не передаются. На телефоне 3D не загружается. Есть светлая и тёмная тема, отмена удаления и демонстрационные данные.

Диди — анимированный помощник и гид по сайту. Он анализирует текущие задачи и отвечает потоковым текстом через RouterAI; HTTPS и реальные потоковые ответы проверены в браузере. Ключ хранится на отдельном сервере. При недоступности AI работают локальные ответы. Серверные Telegram-напоминания настроены; для их получения пользователь лично связывает свой чат кнопкой на сайте и нажимает Start и отправляет `/todo` в Telegram. Доставка в мой личный чат пока не заявляется проверенной.

Первую версию делал с Claude Code, переработку дизайна и функций — с OpenAI Codex. Варианты внешнего вида исследовал через imagegen, а финальный интерфейс реализован кодом. Проверял пользовательские сценарии в браузере; серверные сценарии покрыты тестами.
