Здравствуйте! Тестовое задание готово 🙌

**Сайт:** https://supremegoogle.github.io/The-Digital/
**Репозиторий:** https://github.com/SupremeGoogle/The-Digital

**По заданию** (HTML/CSS/JS, без фреймворков и сборки): добавление задач, отметка выполнения, удаление (с отменой через Ctrl+Z) и сохранение в `localStorage` — список переживает перезагрузку и синхронизируется между вкладками.

**Сверх задания:**
- канбан «Запланировано / В работе / Готово» с drag & drop (мышью, пальцем и с клавиатуры) и корзиной;
- умный ввод: `Сдать отчёт #работа ! завтра` сам ставит метку, приоритет и срок;
- виды «Доска / Список / Календарь», поиск (Ctrl+K), фильтр по меткам;
- карточка задачи с подзадачами, заметками, приоритетом и сроком;
- дашборд: прогресс, KPI, активность за неделю, просрочки;
- небольшой 3D-обзор задач на Three.js (на телефоне не загружается);
- помощник Диди — анимированный робот: считает прогресс, находит просрочки, проводит по интерфейсу;
- Telegram-напоминания о выбранных задачах в заданное время;
- светлая и тёмная тема, заставка с логотипом, адаптивная вёрстка, `prefers-reduced-motion`, демо-данные («Ещё → Добавить примеры»).

Честно про серверную часть: на GitHub Pages работает только статика, поэтому Диди там отвечает в локальном режиме, а Telegram-напоминания показаны выключенными. AI-чат (Router AI, потоковые ответы) и Telegram-бот подключаются через Node-сервер из папки `server/`; локально всё проверено, есть тесты (`npm test --prefix server`). Как развернуть — в `docs/CLAUDE-DEPLOY-ASSISTANT.md` и `docs/TELEGRAM-SETUP.md`.

Где что лежит: `index.html`, стили в `css/`, логика в `js/` (по модулю на функцию), сервер в `server/`, скриншоты и инструкции в `docs/`. Подробности — в README.
